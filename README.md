# Some Shaders I made

A collection of about 26 shaders I designed after working through [p5.js shader examples](https://github.com/aferriss/p5jsShaderExamples); an extremely useful resource for beginner GLSL.

## Running it on your own machine

The easiest simplest way to run these shaders on your machine is to open the project root in VSCode and after having installed the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) right click on one of the html files in a folder inside of /Jesse that you like the sound of and click `Open with Live Server`.

Other than that you can host a bottle endpoint locally using Python or really any web server you want, but I've found the above method is the quickest solution. At some point I will add a directory-esque page so you don't have to keep spinning up new servers.
